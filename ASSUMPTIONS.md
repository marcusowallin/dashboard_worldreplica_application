# Assumptions register

Every assumption and derived value used by the model, in one place. It feeds the page's
"Sources and method" section and the confidence label (06_METHODOLOGY.md section 13).
Update it whenever a new assumption is made. Source levels: L1 company's own printed documents,
L2 company-compiled consensus, L3 other official sources, L4 reputable third party,
L5 labelled assumption (full rule: 03_DATA_REGISTER.md header). Figures and quotes: 03_DATA_REGISTER.md.

Sensitivity = roughly how much the answer changes if the assumption is wrong. Where it needs the
model, it says "to be calculated". "pp" = percentage points.
